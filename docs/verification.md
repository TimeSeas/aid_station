# 本轮验证记录

日期：2026-10-15。环境：Windows、PHP 8.4.26、Node.js 22.23.2、本机微信开发者工具的官方 WXML/WXSS 编译器。

## 已验证

- PHP 源码语法检查。
- 前端自动检查：56 项源码/页面检查，另含会话恢复、失效凭证、错误响应、非法上传响应与聊天定时器生命周期断言。
- 真实 HTTP 集成测试：51 项请求检查，另含身份归属、申请隐私、审核后的宠物状态、未读数、真实图片与伪装图片上传断言。
- HTTP 测试使用独立 SQLite 数据库，结束清理；开发数据库保留演示资料。
- 微信官方编译器检查 27 个 WXML 模板和 29 个 WXSS 样式文件。另已完成下述模拟器运行检查；真机仍需验收。

关键安全回归：匿名不能写入；伪造 user_id 不改变实际作者；账号注册不能自授管理员；用户不能删除别人的评论、修改别人的求助、审核别人的宠物申请，或读取无关私信和领养联系资料；源码、配置、表结构和数据库路径不能通过本地路由下载。

## 微信开发者工具实际运行

- 启动本地 PHP + SQLite 服务，使用 `127.0.0.1:8082` 连接小程序。
- 确认首页读取 3 条示例宠物，详情显示图片、健康信息与领养入口。
- 点击演示登录，确认个人中心显示「演示守护者」。
- 切换论坛标签，确认加载示例动态；打开救助列表，确认显示示例求助和状态按钮。
- 修复模拟器中宠物卡片未按双列排列的问题，并同步更新端口配置、文档和相关检查。
- 保存首页、宠物详情、救助列表、个人中心四张截图至 `docs/screenshots/`，在 README 中展示。

以上为模拟器阅读与登录检查，不包含本次未执行的真机选图、申请审核手工流程或真实微信登录。
